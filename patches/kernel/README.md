# Kernel patches

Patches for the Spotify Car Thing kernel ([spsgsb/kernel-common](https://github.com/spsgsb/kernel-common),
branch `buildroot-openlinux-201904-g12a`, Linux 4.9.113). Apply them in number order to the
kernel tree (`docs/kernel.md`). Linux is licensed under the GNU GPL version 2 only, so these
patches are licensed under GPL-2.0-only (`LICENSES/GPL-2.0-only.txt`).
