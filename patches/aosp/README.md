# AOSP patches

`scripts/aosp-patches.sh` applies `patches/aosp/<project path>/*.patch` to the AOSP tree.
These patches change AOSP projects and the Arm Mali gralloc, which are licensed under the
Apache License 2.0. The patches are licensed under the same license
(`LICENSES/Apache-2.0.txt`), so that they can go back to the projects that they change.
